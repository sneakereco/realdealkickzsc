# Analytics

Production traffic and performance reporting uses Cloudflare Web Analytics. The site loads one manual beacon from `static.cloudflareinsights.com` only when both production deployment variables are configured:

- `CLOUDFLARE_WEB_ANALYTICS_ENABLED=true`
- `CLOUDFLARE_WEB_ANALYTICS_TOKEN=<site token>`

Keep the feature disabled in local and staging environments. Review traffic in Cloudflare's hosted Web Analytics dashboard; the application does not proxy or recreate those reports.

Use Cloudflare's manual installation for this site and leave automatic beacon injection disabled so the root layout remains the single installation point.

Cloudflare Web Analytics is cookie-free and does not receive the visitor/session identifiers previously generated by this application. The forward migration `20260917170000_retire_site_pageviews.sql` deletes the historical `site_pageviews` table. Cloudflare currently exposes six months of Web Analytics data in its dashboard.
